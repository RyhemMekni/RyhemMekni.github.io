DevSecOps infrastructure for AI-agent testing

Delivered an evaluation framework for RAG-based agents (Spring AI RelevancyEvaluator, FactCheckingEvaluator via Ollama/Bespoke Minicheck) that detects hallucinations and scores reliability. Wired it into a 6-stage GitLab CI pipeline combining SAST (SonarQube), dependency scanning (42 CVEs flagged, 11 critical) and DAST (OWASP ZAP), with quality gates blocking builds on critical vulnerabilities or low relevancy, and 10 prompt-injection attacks across 5 families all repelled. Added input sanitization, attack-surface analysis of MCP tools and chaos-engineering tests, with progressive delivery (blue/green, canary), automatic rollback on quality regression and Prometheus/Grafana dashboards. When connected to live web search the agent invented 3 of 4 CVEs, so I built a groundedness evaluator (claim decomposition, then verification against retrieved content) that accepted 2/2 correct answers where the previous factuality judge accepted 0/2.
